# Folio's changes to this fork

This folder is Audiobookshelf's web app (`client/` of advplyr/audiobookshelf, pinned in `UPSTREAM.lock`), kept as a
light fork: upstream updates come in with `scripts/upstream-merge.sh abs-web` (see `UPSTREAM.md`). Every change
Folio makes is listed here and marked `Folio:` in the file, and kept small so upstream changes merge cleanly.

| File | Change |
| --- | --- |
| `assets/folio/tokens.css` | The kit's colour tokens (a copy of `web/static/css/tokens.css`, generated by the kit). |
| `assets/folio/folio.css` | The Encore look: upstream's Tailwind theme colours, greys and font mapped to the kit's tokens, and app.css's grey gradients and scroll bars in the theme's colours. Loaded last. |
| `assets/folio/glyph.svg` | Folio's glyph. The icons are the kit's tile with it: `kit-icons assets/folio/glyph.svg <out> --name Folio`, then `favicon.svg` → `static/icon.svg`, `icon-512.png` scaled to `static/Logo.png` (512), `ios_icon.png` (256), `icon192.png`, `icon64.png`, `icon48.png` and `favicon.ico` (a 32 px PNG, as upstream's is). |
| `nuxt.config.js` | Loads the two CSS files; the name Folio and the theme's background in the page title and the web app manifest. |
| `components/app/Appbar.vue`, `pages/login.vue`, `layouts/error.vue` | The name Folio next to the icon. |
| `pages/config/index.vue` | "Report bugs" links to Folio's repository; upstream's Discord invite is gone (it is upstream's community). |
| `components/app/SideRail.vue` | Links to Folio's own pages (Wanted, Downloads, Review, Move in) at `/folio/`. |
| `.gitignore` | What `npm ci` and `npm run generate` make here. |

Help links to upstream's documentation, issue references in code comments and the changelog's links to upstream
releases stay: they point at the original, which Folio credits in its README.

Built for the root of Folio's server: `ROUTER_BASE_PATH= npm run generate` (the Dockerfile's `absweb` stage).
